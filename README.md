# 채채 테트리스

아이폰 홈 화면에 추가해서 실행할 수 있도록 구성한 PWA 테트리스 게임입니다.
키보드와 화면 터치 버튼으로 모두 조작할 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 public repository를 만듭니다.
2. 이 폴더의 파일을 repository에 업로드합니다.
3. Repository Settings > Pages에서 배포 branch를 선택합니다.
4. 배포된 HTTPS 주소를 아이폰 Safari에서 엽니다.
5. 공유 버튼 > 홈 화면에 추가를 선택합니다.

한 번 실행해 캐시가 완료되면 오프라인에서도 실행할 수 있습니다.
